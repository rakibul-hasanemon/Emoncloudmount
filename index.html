Emoncloudmount

A personal Windows setup using rclone to access Google Drive as a mounted drive.

About this project

Emoncloudmount is the name of a personal configuration project. It uses rclone, an independently maintained command-line program, to connect to cloud storage services such as Google Drive and make files available through a mounted drive on a computer.

What this project does

  • Helps its owner access their own cloud-storage files from a computer.
  • Uses Google's authorization flow to grant rclone the permissions selected during setup.
  • Does not provide a public file-sharing service or a service for other users.

Data and security

This is a personal project, not a commercial cloud service. The project owner does not operate a separate Emoncloudmount server that collects users' Google Drive files. Google authorization and file access are handled by Google and the locally configured rclone application, according to the permissions granted and the software configuration. The owner should protect their computer and rclone configuration, which may contain sensitive authorization credentials.

For more information, read the Privacy Policy.

Third-party software

rclone is third-party software. Google Drive and Google OAuth are Google services, and their own terms and privacy policies apply to their services.
